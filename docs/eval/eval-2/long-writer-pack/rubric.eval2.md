# rubric.eval2 — soft long Writer pack outline (stub)

Not a headed oracle. One document. Soft themes, not brittle regex.

## Criteria themes

| Theme | Pass idea | Fail closed |
|-------|-----------|-------------|
| Pack present | Saved `.odt` / `.docx`; substantial body | Missing / empty / Ready husk |
| TOC | A table-of-contents field or equivalent index at the start | Headings only; no TOC |
| Named styles | Major sections use heading styles (not bold Default) | Entire body Default / unstyled |
| Comments | At least one review comment on a real span | No comments; comment on an empty husk |
| Not GMP / Impress | Single Writer pack; no form-fill pair; no deck | Second form file or PresentationDocument |
| Husk ban | No `Error:` body | Blank or error husk |

Soft / later: exact heading text, comment author names, +5 style, Word
vs ODT.

## Non-goals

- A second change-control form.
- A `--score` CLI in this stub.
